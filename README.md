# Mi Portafolio - Galería de Imágenes

Esta es una página web simple que admite imágenes en una galería responsive.

## Estructura del Proyecto

```
├── index.html       # Página principal
├── styles.css       # Estilos de la página
├── images/          # Carpeta para almacenar imágenes
└── README.md        # Este archivo
```

## Cómo Usar

1. **Agregar imágenes**: Coloca tus imágenes en la carpeta `images/`
   - Formatos soportados: JPG, PNG, GIF, WebP
   - Nombres recomendados: image1.jpg, image2.jpg, etc.

2. **Modificar el contenido**: Edita `index.html` para:
   - Cambiar el título
   - Agregar más imágenes
   - Actualizar descripciones

3. **Personalizar estilos**: Modifica `styles.css` para:
   - Cambiar colores
   - Ajustar tamaños
   - Alterar la disposición

## Características

✅ Diseño responsive (se adapta a dispositivos móviles)  
✅ Galería con efecto hover  
✅ Fácil de personalizar  
✅ Muy ligera y rápida  
✅ Compatible con todos los navegadores modernos  

## Próximos Pasos

1. Crea la carpeta `images/` en tu repositorio
2. Sube tus imágenes a esa carpeta
3. Personaliza los colores y textos según necesites
4. Tu página estará disponible en `https://danirojestr.github.io`

---

**Nota**: GitHub Pages necesita que la carpeta se llame exactamente `images/` para que el sitio pueda acceder a ellas correctamente.
